## 二、核心设计决策（下次别再走回头路）

### 1. 原卷不能直接搬——必须重排题型

`content/资料/26新{二,四}年级上册语文【口语交际】专项练习.pdf` 两份都是**纯扫描件**
（PyMuPDF 提取只有水印「温老师教育」），10 + 9 页，150dpi 渲染后逐页精读。
原卷形态是「大量开放填空 + 写话」，答案区自己都写「答案不唯一，仅供参考」。
直接做成 blank 会被精确匹配全判错。重排规则：

- 交际要求 / 得体性 / 表达方法 → `single` / `multiple` / `judge`（唯一答案）
- 制作步骤、资料分类、做法与要求对应 → `matching`（左短标签 + 右整句，索引配对）
- 真正要"说出来"的表达 → `essay` + 显式 `keyPoints`

### 2. 口语交际包必须 `examMode: false`

**这是本次最容易改错的地方。** `QuizEngine.vue` 的两处门禁都是 `!examMode`：
- 190 行 `feedback-box`（判分反馈 + 得分点清单）
- 1125 行 音效

开 `examMode: true` 就只剩「交卷后统一判」，essay 的 `missing`（你漏了哪几个点）
永远看不到——而这恰恰是口语交际包唯一的价值。与 `special-chinese-2-up-kantu` 同款取舍。
已在 `tests/oral-pack-essay.test.ts` 用断言钉住（`examMode` 必须为 false）。

### 3. `module.type` 只能用已注册的 13 种

一开始给 topic 写了 `chinese.oral`，但 `src/core/registry/registerAll.ts` 里根本没有这个类型
（语文只有 `chinese.poem` / `text` / `words` / `writing`）。未注册类型 → 知识点卡片不渲染。
改用 **`chinese.writing`**：`ChineseWriting.vue` 就是把 kp 的 `title + content` 渲染成
markdown 卡片，正好承载「交际小技巧」。测试里已加白名单断言。

### 4. essay 得分点要写成「要素族」，且 ≥3 组

判分走 `@core/quiz/essayGrade`：`pointCovered` 双向包含 + `/` 同义备选，阈值 0.6。
两条硬约束（脚本 `_check_essay_points` 会直接拦）：

1. **每题 ≥3 个得分点**。2 个点时 0.6 阈值要求全中（2/2=1.0），比 4 个点还严；
   3 个点中 2 个（0.67）才是设计意图。4 个点要中 3 个（0.75）。
2. **每个备选 ≥2 字**。内核 `if (a.length < 2) return false` 会静默丢掉单字，
   写「先/再/然后」里的「先」「再」等于白写。首轮自检就抓到 5 处（含「再」「哭」「问」「累」「歇」）。

得分点的写法是"必须说到的要素"，不是"标准答案里的词"：
```
"样子/外形/长得/毛色/耳朵/眼睛/尾巴/全身"   ← 外形要素族
"爱吃/最爱/睡觉/本领/习惯/平时/会跑/会跳"   ← 习性要素族
"可爱/有趣/真好玩/真有意思/很喜欢"          ← 感受要素族
```
孩子写「它全身毛茸茸的，眼睛圆圆的，特别可爱。它爱吃骨头」→ 三组全中，判对。

### 5. 得分点太松也会翻车（同一道题要两头验）

`o2-u4-09`（兔子迷路）最初组 1 含「小兔子」、组 3 含「回家」，
敷衍答案「小兔子回家了」就能中 2/3 判对。改法：
- 组 1 去掉必然出现的主语「小兔子」，换成「迷路/害怕/着急/找不到/哭了」
- 组 3 去掉泛词「回家」，换成「带路/**带你回家**/送你回家/跟着/照路」

结论：**每个得分点都要问一句「最偷懒的答案能不能蒙中」**。

## 三、回归护栏（新增）

`tests/oral-pack-essay.test.ts`（16 例，读 `content/` 真实交付文件，不是内嵌副本）：

- 结构：题型白名单、single 答案在选项字母内、multiple 至少 2 个答案、
  matching 索引不越界且右项不重复配对、essay 得分点 ≥3 且备选 ≥2 字
- 必须 `examMode:false` + `module.type` 在白名单
- **自洽**：每道 essay 的参考答案自己必须判对
- **区分度**：每题一个「认真作答」样本判对 + 一个「敷衍作答」样本判错（16 题 × 2 条，逐个手写）

改包不更新这个测试会直接红。这正是想要的护栏——上一批看图写话只做了口头实测，
没有固化，这次补上。

## 四、顺带修的 UI

`QuizEngine.vue` matching 的 `<n-select style="width: 200px">` 写死了宽度。
语文「按顺序排步骤」的右项是整句（"沿画好的线剪出半边蝴蝶的形状"），200px 只能露一半。
改成 `.matching-select { flex: 1 1 200px; max-width: 380px; }`。
**此改动需重建 App 才生效**，不影响当前 zip 导入使用。
