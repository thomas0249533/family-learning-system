### 判定与偏离
1. **腐坏题目的 userAnswer 是展示串**：练习模式 `AnswerPayload.userAnswer` 是 `formatUserAnswer()` 的结果（这是 QuizEngine 既有契约，不改 emit 签名）。多选/连线/多陈述判断题恢复时直接塞回 v-model 会炸（`"AB"` 进 checkbox-group）→ QuizEngine 内加 `coerceAnswer()` 按题型降级（能还原就还原，还原不了留空，题目照看）。
2. **未做态颜色**：任务书写的 `--text-tertiary` 在本仓**不存在**（全仓 grep 零命中），三级文字语义由既有 `--text-muted` 承担，已在 QuizEngine 样式处注释。
3. **QuizEngine 新增内部态 `practiceAnswers`**（qid→{userAnswer,isCorrect}）：`answeredSet` 只有下标没有对错，`examAnswers` 只在考试模式维护且对错要等 finalizeExam——语义不同，不混用。
4. **答完即 finished**：若不挡卸载时补发的 save-progress，「完成练习」会在下次进页时变成「继续上次」——这是本线最容易埋的雷，已有注释 + e2e 覆盖。
