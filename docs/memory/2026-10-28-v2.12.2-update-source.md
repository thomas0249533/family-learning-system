# V2.12.2 · 更新链路换源（2026-10-28 16:20）

## 起因：家庭端在 2.12.1 上点「检查更新」→「已是最新版本（v2.12.0）」

远端 main 的 `latest.json` / `version.json` 明明都是 2.12.1（用 API 直读确认），
Release v2.12.1 也已发布。**代码逻辑一行没错，错在地址。**

三处叠在一起：

1. `raw.githubusercontent.com` 在国内常被拦 —— 而它是 updater 的**第一顺位**；
2. `cdn.jsdelivr.net/gh/<repo>@main` 对**分支**内容有 **12 小时缓存** ——
   发版 20 分钟时读到的是发版前的清单 → 客户端判「已最新」；
3. `latest.json` 里的安装包 url 也指向 jsDelivr 的 `@main` 路径 ——
   发版当天那个新路径在缓存刷新前是 **404**，就算清单读对了也下载不动。

第 3 条是真正致命的：**清单有四个源可切，安装包只有一个地址**。

## 改法

| 位置 | 改动 |
|---|---|
| `src-tauri/tauri.conf.json` | endpoints 首位 → `releases/latest/download/latest.json`（动态重定向、无长缓存）；raw / jsdelivr / gitmirror 退为兜底 |
| `scripts/gen-latest.mjs` | 安装包 url → `cdn.jsdelivr.net/gh/<repo>@v<ver>/updates/<ver>/<bin>`（**tag 固定路径**） |
| `src/core/update/checkUpdate.ts` | D-1 降级主源 → `releases/latest/download/version.json`（候选从 3 个变 4 个） |
| `scripts/publish-release.mjs` | 把 `version.json` 也上传为 Release 资产 |
| `scripts/check-remote.mjs` | 增加 Release 清单与 version.json 资产校验 |

### 为什么安装包用 `@v<ver>` 而不是 github.com 直链

实测本机：`github.com` 曾连续超时（后来恢复），`objects.githubusercontent.com` /
`uploads.github.com` / `cdn.jsdelivr.net` 都通。安装包下载没有兜底，不能押在一个
时通时不通的域名上。

`@v2.12.2` 这个 tag 是发版时才创建的，该 URL **从来没被缓存过** → jsDelivr 首次
请求直接回源 GitHub；而它指向的内容永不变 → 之后缓存住也无妨。
**既不会 404（新路径没缓存），也不会拿到旧包（内容不变）。**
与 2.12.1 的唯一差别就是 `@main` → `@v<ver>`。

## 实测结果（本机）

- `releases/latest/download/latest.json` → HTTP 200，version=2.12.2 ✅
- `releases/latest/download/version.json` → version=2.12.2 ✅
- 安装包 URL：jsDelivr 本机不可达，退化为仓库内 blob 比对（6.31MB 一致）
- `check-remote.mjs` 全环通过

**待家庭端验证**：能否连通 `github.com`（主源）与 `cdn.jsdelivr.net`（下载）。
两者都不通时，只能拷便携版。

### 画插画踩的坑（下次直接照这个改）

- **多格连环画的裁剪 id 不能猜**：`clip_def` 必须返回 id，作者不能写死 `#c1/#c3/#c5/#c7`
  —— `defs` 数组长度会因为中途 `sky()` 加渐变而漂移，编号全错，内容溢出格子。
- **`person(pose='run')` 的鞋**：原来统一画在 `foot_y`，跑/跳姿势下脚的真实落点不在那儿，
  渲染出「两只鞋脱在身体下面单独飘着」。改成按姿势给出 feet 坐标。
- **躺姿不能用站姿旋转**：`pose='lie'` 画出来像在做体操。另写 `fallen()`，按躺姿重新摆点位。
- **球在缸里**：直接画在缸口上方会被看成「一只白眼」。要裁剪到缸口椭圆里。
- **敬礼/指方向的手**：手停在脑袋侧面会被读成「挠头/摸耳朵」，必须伸到头部轮廓之外。
- **室内场景别套草地逻辑**：地平线一条横线 + 人在黑地里 = 站在野外。要画墙/地/家具。
- **题卡是 `max-height: 320px`**：竖图缩下来只剩一条；多格图必须更宽（测试已钉死比例）。
