## C2 · 盲盒引擎（新文件 `blindBox.ts`，18 单测）

- 5 枚盲盒专属成就（bb-lucky-star/moon/rainbow/comet/crown，category E，check 恒 false，不进图鉴）。
- 触发：单日解锁≥3（滤 night-owl/盲盒 id/非内置）→ `effectiveCurrent(streak)≥7` → 单日专注≥60 分钟。
- 两个关键设计裁决：
  1. **防反馈回路**：盲盒 id 必须从「单日解锁≥3」计数中排除（否则抽 1 次本身+2 枚普通成就就会再触发）。
  2. **防刷锚点记在抽取时**而非触发时：孩子今天不点、明天点照样能抽——约束抽取动作，不惩罚注意力。
- 必出未拥有（随机取余兜底非法 rand）；集齐 5 枚后系统失效自动隐藏。
- `blindBox` 键走完整 settings 链：PROFILE_SCOPED_KEYS 登记 + mergeSettings RULES
  （owned 并集保序 / usedDays 并集排序）+ check:settings-keys 访问点计数 46→48。
