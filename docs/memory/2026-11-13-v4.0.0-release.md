## D5 实现要点（提交 `2a342a4`）
- **焦点环的起因是量出来的**：原 `--focus-ring: rgba(--primary-rgb, 0.55)` 压在浅底上
  实测 ~2.4:1，达不到 WCAG 1.4.11 对非文本对比度的 3:1 —— 环"存在"但看不清，视觉上等于
  没有焦点态。改成 `var(--primary-text)`（~6.4:1），6 组预设 × 浅深全过。
  **教训**：`rgba(主色, α)` 的对比度不是常量，取决于底下是什么；焦点指示器不能半透明。
- 三个变体 token：`--focus-ring-on-strong`（主色/深色面上的环，深绿环压深绿底等于没有）、
  `--focus-ring-offset-inset`（`overflow:hidden` 容器用内嵌环）。
  `components.scss` 与 `tokens.ts` 的 COMPONENT_TOKENS 必须双向同步（有测试锁）。
- 38 处本地环 → 76 条声明全 token 化。原先写法五花八门：20×`2px solid $primary-color`、
  12×`var(--primary-text)`、2×3px、1×`$warning` 色环、1×`var(--on-strong)`。
  `$primary-color` 这种 SCSS 门面变量看着"像 token"，其实绕过了焦点环语义，换预设不跟随。
- **v-clickable 指令**（`src/core/a11y/clickable.ts`，全局注册 + GlobalDirectives 声明）：
  卡片/行这类 `div + @click` 补 `role` / `tabindex` / 键盘激活。两条硬规则：
  · 跳转用 `v-clickable:link` → `role="link"`，**只有 Enter 激活**，Space 留给页面滚动；
  · 动作用 `v-clickable` → `role="button"`，Enter 与 Space 都激活，Space 要阻止滚动。
  指令用 `el.click()` 复用元素已有的 `@click`，**不另建入口** —— 否则两套路径行为必然分叉。
  按键判定抽成纯函数 `resolveKeyAction` / `resolveRole`：测试环境是 `node`（无 DOM），
  不抽出来就只能做静态断言，"链接按 Space 不激活"这种最容易写反的地方就测不到。
- 遮罩上的 `@click.self` **不算控件**（门禁显式跳过）：它是"点空白关闭"，键盘出口是 Esc。
  顺手补了盲盒弹层的 Esc —— 此前键盘用户开箱后没有任何出口。
- 用 `title` 当可访问名字**不合格**（触屏不显示、部分读屏处理不一致），门禁只认
  `aria-label` / `aria-labelledby`。这条收紧了 5 个只有 `:title` 的朗读按钮。
- **彩色面上的对比度**：首页欢迎横幅是主色渐变面，其上「技能树」按钮沿用默认深色字，
  实测 ~1.5:1。横幅内改 on-strong 白字白边，焦点环同时切 `--focus-ring-on-strong`。
  坑：naive 把 `--n-*` 写在按钮**行内 style**，类选择器赢不了，只有 `!important` 能盖
  （已在注释里写明这是与 naive 打交道的固定代价，别当偷懒）。
- 门禁 `scripts/check-a11y.mjs` 三条规则；`tests/a11y-adoption.test.ts` 17 条（含
  「旧 55% 方案必然跌破 3:1」的反证 —— 防止有人"审美上"改回去）；
  `tests/e2e/a11y-keyboard.spec.ts` 用真浏览器验证可聚焦 + 环可见 + Enter 真跳转。

## D6 实现要点
- **结论先摆出来**：token 级的「图标 × 彩色面」**全部达标**（40 处登记 × 6 组，must 档最低 4.51）。
  真正的问题不在 token，而在**没人把图标当图形审过**：`currentColor` 的色是继承来的，
  token 表里看不出它落在什么底上。
- **测出来的两类真问题**：
  1. **`-color`（图形色）当实心底 + `text-on-primary` 前景**，实测 `primary.light` **2.85:1**
     —— 比 WCAG 1.4.11 给非文字的 3.0 还低。共 **10 处**：大图关闭 ×（控件！）、古诗/英语朗读
     按钮的播放中态、词语背记模式选中态、盲盒「？」、首页快捷胶囊、成就墙印章，外加 3 处
     `:hover`（错题本 ×2、复习页攻击按钮）。全部改 `-text` 底 → 5.12:1。
     **这条约定 6a 就写进报告了，但没有任何机器门禁**，所以又长回来了 —— 报告里
     `notApplicable` 那句「-color 上不再有白字」早就不成立。
  2. **品牌渐变上的图标**：`gradient-primary` 浅端太亮，白压浅端 1.97、深字压深端 1.70，
     **不存在**一个前景色能同时过两端。渐变已定档不动 → 登记为 `brand` 档，
     写死实测下限（1.51–1.97）守「不得变差」，不再沉进「不适用」。
- **登记表** `src/core/a11y/icon-spots.ts`（40 条 × 6 组 = 240 对）：
  `file + cls + 前景/背景解析器 + 档位`。两档 `must`（3.0）/`brand`（下限）。
  背景解析器收 `(sem, mode)` —— **mode 必须传**：同一个类在浅/深可能用不同 alpha
  （`QuizEngine .explanation` 浅 65% 白、深 6% 白），拿单一 alpha 套两套主题会算出
  「浅色主题的深字压在近白蒙层上」这种不存在的组合 = 伪造红灯。
- **踩过的坑**：组件级别名（`badge-primary-bg`）**不在** `buildSemantic` 里，是
