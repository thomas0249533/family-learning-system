## G3 · 跨设备二维码分发
- `vendor/qrcodegen.ts`：Project Nayuki 的 `qrcodegen`（MIT，单文件纯函数），
  **保留许可证头**、不进 `package.json`（零新 npm 依赖）。
- `qrcode.ts`：载荷字段白名单（type / pkgId / checksum / url）——
  **安全红线：字段表里根本没有口令/Key 的位置**（二维码会被拍照外传）；Canvas 渲染。
- `parser.ts`：协议白名单 + 字段白名单 + 长度上限 + checksum 校验；恶意输入
  （注入串/超长/伪协议/缺字段/坏校验和）返回**结构化错误对象**，绝不 `v-html`。
- UI：`learn/PackageList.vue` 分享按钮（`.pkg-share-btn` → 弹窗 Canvas）；
  `settings/ImportWizard.vue` 扫码导入（`BarcodeDetector` 特性检测，不可用则手输后缀码）。
- 测试：单测 31 条（含防御性解析全集）；e2e `share-qrcode-{light,dark}.png`
  （断言 Canvas 暗像素 > 200：证明真的画出了 QR 而不是空白）。
