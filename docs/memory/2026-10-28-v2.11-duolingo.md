### 一、语文阅读主观题（前一阶段完成）
- 新增 `src/core/quiz/essayGrade.ts`（纯函数）：参考答案拆得分点（显式 `keyPoints` 优先，否则按句 → 句内顿号/逗号细分，并剥掉「使用了/…手法」前后缀露出核心词）；判分 = 覆盖率达阈值（默认 60%）即对，另有整段 bigram 相似度回退捕捉「换说法」；`/` 支持同义备选。
- `QuizEngine`：essay 与标为主观的填空/拼写走 `gradeEssay`；反馈区展示参考答案 + 🎯得分点清单（命中 X/total）+ 系统判定，判错可手动纠正（同步掌握度/错题本）。

- **使用前提**：现有阅读包里类型是 `blank`/`spelling` 的短答题必须标 `subjective: true` 才走主观判分。

### 二、多邻国风视觉与反馈（本阶段）
- **token 扩容**（唯一源 `tokens.ts` + 生成器 `scripts/tokens/emit.ts` 两处同步）：
  - `RADIUS['2xl'] = 24px`
  - `NEUTRALS[mode].shadow3d` / `shadowBadge` / `progressGloss` —— **明暗必须两套**：浅色 `rgba(22,38,31,0.20)`，深色必须加重到 `rgba(0,0,0,0.55)`，否则深底上积木厚度直接消失。
- **UI 基元**：`AppButton` 加 `.app-button--3d`（border:0 + `--shadow-3d`，`:active` 下移 4px 且阴影归零；ghost/dashed/quaternary/text/tertiary 不加厚度）；`AppCard` border:0 + radius-2xl，danger 改 inset 描边；`ProgressBar` 默认渐变 + `::after` 顶部高光；`AchievementCard` 加 `--shadow-badge`（保留 border，因其承担状态色语义）。
- **反馈引擎**（新建 `src/core/feedback/`，照抄 `NoiseGenerator` 范式）：
  - `AudioEngine.ts`：OscillatorNode 合成三种音（correct Sine 880→1320 / wrong Triangle 196→146 + 900Hz 低通 / click Square），惰性建 ctx、播放前 resume、`navigator.webdriver` 判自动化静默、异常全吞、单例复用。
  - `haptics.ts`：封装 `navigator.vibrate`（20 / [50,50,50]）。**Windows WebView2 无此 API，家庭端恒静默**。
  - `feedbackSettings.ts`：`fls:feedback` 键（**global**，设备级），内存镜像让答题反馈走同步路径。
  - `index.ts`：门面 `playCorrectFeedback` / `playWrongFeedback` / `playClickFeedback` / `syncFeedbackEngine`。
- **接入**：`QuizEngine` 提交与手动纠错时发声 + 选项框染色（`.opt-item--correct/--wrong`，用**双类选择器**压过 `&:hover`）+ `opt-pop`/`opt-shake`/`fb-rise` 动画；`AppButton` click 播 `playClick`；`AppShell` 用 `requestIdleCallback` 延后载入偏好（不占首屏关键路径）；`Settings` 新增「声音与反馈」分区（第九个）。
