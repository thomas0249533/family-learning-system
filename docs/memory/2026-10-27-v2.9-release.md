## 关键坑（下次发版必看）
1. **pre-commit 门禁检查工作树，但 `git commit` 用暂存区(index)**：编辑已暂存文件后直接 commit，远端可能落入旧的 index 内容。本次 `graph-subjects.spec.ts` 的 `profileId`(TS6133) 在首推时仍在 index 中（门禁却对修改后工作树放行），导致远端首提交含未修版本。修正：commit 后务必 `git show HEAD:<file>` 核对；已用补充提交 `f9227df` 修复并 repoint tag。
2. **推送走 GitHub REST API（Git Database）**：`git push` over https 被代理拦截（schannel SSL handshake 失败）；`api.github.com` 可达但 `raw.githubusercontent.com` 偶发 ECONNRESET。`curl` 传大 base64 触发 ENAMETOOLONG（Windows 命令行上限）——改用 Node `fetch` 直传 blob+tree+commit+ref PATCH，`base_tree` 取远端树，绝不在 tree 里直接带 content。本地/远端 commit SHA 不同但树一致属正常。
