## 轨道 A · 极致 UI（commit c602404）

### A1 设置页左菜单（`src/views/Settings.vue`）

- 左栏 8 个分区（外观 / AI / 学习包 / 导出 / 备份导入 / 同步 / 搜索历史 / 危险操作），
  粘性定位；≤900px 降级为顶部横向可滑分区条。
- **关键取舍**：用「滚动定位 + 滚动反算高亮」而不是「Tab 只渲染一屏」。理由三条：
  1. `LocalAiCard` / `SyncSettings` / `ImportPreview` 是自治组件，卸载重建会丢内部状态
     （同步轮询、备份预检结果）；
  2. `#family-backup` 深链是 B4 的既有契约，只渲染一个面板时目标元素常处于
     `display:none`，`scrollIntoView` 必然失败；
  3. 全部内容常驻 DOM → e2e 的可见性定位、浏览器 Ctrl+F 都照旧。
- 两个真实坑（都已修）：
  - **平滑滚动抢高亮**：`scrollIntoView({behavior:'smooth'})` 连续派发 scroll 事件，
    反算逻辑会依次点亮路径上经过的分区。加 700ms「程序化滚动静默期」。
  - **触底永远顶不到**：最后一个分区下面没有内容，其 `top` 到不了阈值，
    反算会长期停在倒数第二个。加上"滚动容器触底 → 直接判定最后一个分区"。

## 轨道 B · 心流声学（commit 05f04ff）

### B1 更精细的合成（`src/core/focus/NoiseGenerator.ts`）

- 新增 `ocean`（海浪）/ `stream`（溪流）两种音源。
- 慢速 LFO：雨 0.05Hz 游移高通、海浪 0.07Hz（≈14 秒一个潮汐）、溪流 0.6Hz 带通颤动。
  只调制 `filter.frequency`，**不碰增益结构** —— 音量滑块的语义与调制度互不耦合。
- `teardownNodes` 先停 LFO 再断 source；`createOscillator` 不存在时自动跳过调制。

### B2 本地音频导入（新增 `src/core/focus/customSoundStore.ts`）

- db 升到 `version(6)`：新表 `customSounds`（`++id, [profileId+soundId], profileId, createdAt`），
  纯新增表、**不写 upgrade 钩子**（与 v5 加 topicSessions 的做法一致）。
- 限额：单个 ≤ 8MB、最多 5 个；MIME 缺失按扩展名兜底；同名同体积判重；
  写库抛错（配额爆掉）转成 `too-large`，不把异常抛给 UI。
- 播放走 `NoiseGenerator.startBuffer` / `decodeToBuffer`：
  - 解码结果**用完即弃**（5 分钟立体声解码后约 100MB，缓存几个就能卡死低配平板）；
  - 不产生 objectURL → "释放 Blob"在架构上就是免费的（删除行即释放）。
- `FocusMode` 的音源选择收敛成**一个** `source` 状态机（内置 / `file` / `off`），
  杜绝"两个按钮同时高亮"。

## 轨道 C 为何未开工（待决）

1. **不是时间问题，是不变量的代价**：10 枚习惯成就不是"再加十条 JSON"。它们牵动
   `ACHIEVEMENT_TOTAL_DEFINED`（28→38）、`achievementTaxonomy` 的
   source/tier 分布断言（core 7 · subject 13 · habit 5 · hidden 3）、
   `achievementProgress` 的「进度 ⇔ check」等价性、`achievementToast` 层级权重表，
   以及 `achievements.test.ts` 里**故意冻结的 28 枚 check 快照**（AC-01）。
   这些正是"系统长盛不衰"的地方，一次性冲进去风险高于收益。
2. **盲盒是新子系统**（抽奖引擎 + 保底计数 + 开箱动画 + 触发条件 + 与成就/toast 的边界），
   应当独立一轮、独立门禁。
3. 用户叮嘱的"合并 Home.vue 冲突"在本次已自然规避：A2 把首页改成新组件，
   三条线不再同时改同一段模板；C 落地时只需在 Home 增加一个入口区块。

**建议**：C 单独一轮，顺序为 ① 10 枚习惯成就（含 taxonomy/progress/toast/快照的成套迁移）
→ ② 盲盒引擎（纯函数 + 单测）→ ③ 开箱动画与首页入口 → ④ 全量 e2e + 基线复核。
