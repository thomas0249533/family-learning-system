## 本次发版的坑（都是「出错时日志看着像成功」）

### 1. 签名环境变量名不对

`TAURI_SIGNING_PRIVATE_KEY_PATH=.tauri/family-learning.key` **不被本机 CLI 识别**（v2 CLI 只读
`TAURI_SIGNING_PRIVATE_KEY`）。现象：Rust 编译 3 分钟、NSIS 也打出来了，最后一步
`Error A public key has been found, but no private key` 退出，白等一轮。

正确写法：`TAURI_SIGNING_PRIVATE_KEY="$(cat .tauri/family-learning.key)"`。
私钥文件是单行 base64、无密码，不需要 `_PASSWORD`。

### 2. 上传 20MB 资产偶发 504 —— 数据其实已落库

`POST uploads.github.com/.../assets` 返回 504（HTML 错误页），但资产**已经完整上传**。
原脚本直接抛错；重跑时又传了一份 `app2026-10-28b.exe`（内容与 a 完全相同），事后删除。

修法：失败后先回查远端资产大小，与本地一致即认定成功；不一致则删掉再传。

### 3. 「已存在就跳过」不校验大小

原逻辑 `existing.has(name)` → 传了一半的坏资产或旧包都会被永远跳过。
改为比对字节数。

### 4. tag 指向本地 HEAD 会得到孤立 tag

推送走 tree API 重建提交，远端 SHA 与本地 HEAD **不同**。用本地 HEAD 打 tag，tag 不挂在 main 上。
改为读远端 `git/ref/heads/main`。

### 5. 本机 DNS 解析不了三个 CDN 域名

`api.github.com` 通（走 `127.0.0.1:51549` 代理），但 `raw.githubusercontent.com` /
`cdn.jsdelivr.net` / `raw.gitmirror.com` 直连与走代理都失败（curl exit 6 = DNS 解析失败）。
所以**在这台机器上无法实测更新清单与安装包可达性**。
`check-remote.mjs` 为此加了等价校验：网络失败时改用 API 读 main 的 blob，比对内容与字节数。

⚠️ 遗留风险：家庭端能否拉到 `latest.json` 取决于它自己的网络，本机无法证明。

## 新增/改动的工具

| 脚本 | 作用 |
|---|---|
| `scripts/check-version.mjs` | 六处版本号 + 两 lock 必须同值；已置于 `verify` 首位 |
| `scripts/gen-latest.mjs` | 从 `.sig` 生成 `latest.json` 并归档到 `updates/<ver>/`；自证签名内文件名/版本 |
| `scripts/check-remote.mjs` | 逐环验：tag→Release→资产→清单→安装包→签名（CDN 不可达时自动降级为仓库内校验） |
| `scripts/publish-release.mjs` | 改：版本号由 `version.json` 推出、失败回查、大小比对、tag 取远端 main |
| `scripts/check-release-assets.mjs` | 查看某 Release 资产清单 |
| `scripts/delete-release-asset.mjs` | 删除重复/坏资产 |

## 发版命令序列（下次照这个走）

```bash
# 0. 升 6 处 + 2 lock，然后
node scripts/check-version.mjs          # 必须 7 处一致
npm run verify                          # 首位就是 check:version

# 1. 构建（~6min，rust 有缓存；清过 target 则 ~52min）
export PATH="$PATH:/c/Users/Administrator/.cargo/bin"
TAURI_SIGNING_PRIVATE_KEY="$(cat .tauri/family-learning.key)" \
  CODEBUDDY_SAFE_DELETE_ENABLED=0 npx tauri build 2>&1 | tee .tmp/build.log
grep "Compiling app v" .tmp/build.log   # 版本号必须对

# 2. 更新清单 + 归档
node scripts/gen-latest.mjs

# 3. 提交
git add -A && git commit -m "chore(release): x.y.z"

# 4. 推送（git 协议被代理拦，走 REST）
node scripts/push-to-github.mjs

# 5. 建 tag + Release + 传资产
node scripts/publish-release.mjs

# 6. 逐环验证
node scripts/check-remote.mjs
```
