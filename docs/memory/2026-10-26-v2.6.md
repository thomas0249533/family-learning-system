# 2026-10-26 · V2.6 体验补丁（词汇表折叠 + 词语表切换 + e2e 修复）

基线 v2.5.0。用户反馈：词汇主题里「开始背记」被大量知识点行顶到屏幕下方；
V2.5 新增「检查更新」后 creator e2e 出现 strict mode violation（页面两个同名字按钮）。

## 根因（实测，不是猜）
- 词汇包 `content/chinese-4-up-rjb/special-chinese-4-up-vocab.json`：3 个单元，
  每个单元 `knowledgePointIds` 为**空数组**，真正的词在
  `unit.topics[].modules[].knowledgePointIds`（81 / 90 / 49）。
- 旧 `ChineseWords.vue` 用 `u.knowledgePointIds ?? props.knowledgePointIds`：空数组
  不是 null，`??` 不兜底 → 选中单元后拿到 `[]`，切换失效 / 词表清空。
- 页面顺序：`TopicDetail` 先渲染「📈 本主题掌握情况」（把 81/90/49 行词条全平铺），
  再渲染模块卡片 → 「开始背记」被顶到很下面。

## 已交付
- 新增 `src/core/content/unitKnowledge.ts`：`deriveUnitKnowledgePointIds(unit)` 纯函数，
  优先单元显式字段，否则从 topics/modules 汇总去重（兼容 `knowledgePoints` 旧字段）。
- `ChineseWords.vue`：词语表改为顶部「词语表」下拉（`#vocab-unit-select`），切换即刷新
  词卡与背记队列；词语明细包进 `<details>` **默认收起**，首屏即可见「开始背记」。
- `TopicDetail.vue`：**仅词汇主题**（`isVocabTopic`）把「本主题掌握情况」改为 `<details>`
  默认折叠；非词汇主题保持原样（不改数学/英语页面）。
- e2e 修复：`CatalogSync.vue` 检查更新按钮加 `data-testid="catalog-check-update"`；
  `creator.spec.ts:148` 改用 `getByTestId`，不再用 `getByRole(name:/检查更新/)`。
  AppShell 两个按钮也补了 `app-check-update-sidebar/header` testid 以备未来。
- 新增测试：`tests/unit-knowledge.test.ts`（5 例，含真实词汇包"单元 KP 为空"形态）；
  `tests/e2e/vocab-ui.spec.ts`（首屏可见 + 折叠 + 下拉切换，种子包复刻真实空 KP 形态）。
