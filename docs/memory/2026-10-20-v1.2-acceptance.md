## 二、修法里值得沿用的两条

- **生成器里能推导就不要字面量**：大号判据改成从 `tokens.FONT['3xl']` 取，改 token 即改判据；
  字重 800 不是 token，只能照抄并注明来源 —— 别为了"自动化"去解析 `.vue` 源码。
- **文档里不要写源码行号**：这次三条全错就是证据。改成「文件 + 选择器/用途名」。

## 两条踩坑（e2e）
1. **种子数据必须等应用建完库再裸开 IDB**：Dexie 升级期间裸 `indexedDB.open` 会被 block，
   而没挂 `onblocked` 就是**静默挂到 90s 超时**。等 `.ach-card` 计数到位再开，并补 `onblocked` reject。
2. **集齐后不能断言 `.ach-card` = 28**：28 张全在默认收起的「已获得」区 → 实际渲染 0 张。
   要断言总览卡的 `28 / 28` 或 `.ach-head-count` 的「全部收集完成」。
