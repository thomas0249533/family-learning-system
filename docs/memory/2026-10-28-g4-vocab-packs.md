## 三、关键发现与决策

### 1. 语文原包不是空壳，是「有词无题」

`special-chinese-4-up-vocab` 原本已有 **220 个 `type:"word"` 知识点（词语 + 教材标注拼音）**，
只是 0 道题。用 `pypinyin` 逐条交叉校验：**只有 7 处不一致，且全是教材标注的轻声**
（模糊 mó hu、苍蝇 cāng ying、脑袋 nǎo dai、舒服 shū fu、玻璃 bō li、胳膊 gē bo、主意 zhǔ yi）——
教材是对的，pypinyin 按单字本调。**所以这 220 条拼音直接沿用，只给新增的 114 个词补拼音。**

⚠️ 踩过的坑：脚本第一版直接从 SRC 读老包的拼音，**第一次生成就把 SRC 覆盖了**，
第二次跑就读到自己的产物、`KeyError: 'metadata'`。
修法：把 220 条拼音固化到 `scripts/content/data/cn4-pinyin.json`，脚本只读这个数据文件，
SRC 只作输出。

### 2. pypinyin 的多音字要人工兜底

新增 114 个词里只有 1 处真错：**铺开 = pù kāi**（动词应读 pū，pù 是「店铺」）。
另按教材习惯补了轻声：嘴巴 zuǐ ba、熟悉 shú xi。
→ 脚本里留了 `PINYIN_FIX`（人工纠正，优先级最高）和 `NEUTRAL_TONE` 两个字典。

### 3. 英语原包是**沪教版**，与资料完全不重合

原 `special-english-4-up-vocab` 的 128 个词是 city / building / flat / street（沪教版），
`edition` 也标着「沪教版」，而资料是人教 PEP（PE / job / doctor / farmer…）。
→ 整包重建为 PEP 6 单元，`_set.json` 的 edition 一并改「人教版」。

### 4. 单空填空是**严格匹配**，短答案不必改成选择题

一开始以为 `blank` 的子串容错会让 answer=`PE` 时孩子写 `type` 也判对，于是把 12 个
<4 字母的词改成了选择题。后来逐行读 `@core/quiz/blank` 才确认：

- `gradeBlankStrict` 的单空分支**只做严格相等**（外加去括号）；
- `partsMatch` 的子串阶梯只在「多空（有逗号）」和「斜杠备选」两条路径上生效。

所以 `PE` / `Ms` / `his` / `is` 做单空填空**不会**被蒙对。已改回统一的中译英填空
（109 个词题型一致），只在**多空答案**（`driver, drives`）时才需要注意每段取长一点。

### 5. 成语补字的答案只能是**缺的那部分**

第一版把答案写成整词（`（　）（　）鼎沸` → 「人声鼎沸」），孩子按题干只会填「人声」，
会直接被判错。改成「缺什么填什么」：连着的两个空 → 一段两字（`人声`）；
被字隔开的两个空 → 逗号分两段（`横,竖`）。
`精忠（　）国` 这类单字空写成备选 `报 / 报国`，两种填法都算对。

### 6. 原卷「从方框选词」不要把方框贴进题干

英语语法有一组 A–F 选词填空，第一版把整个方框贴在每道题干后面，变成一长串噪声。
改成四选一（正确项来自原题，干扰项也只取原方框里的词）。

## 四、回归护栏（tests/g4-packs.test.ts，14 例）

最值钱的两条是纯数数就能验、却能抓住绝大多数转录错误的：

1. **音节数 == 汉字数**：`qí guān → 奇观`。拼音音节数与答案字数不相等，一定是抄错了。
   335 道看拼音写词语全过。
2. **空位数 == 答案字数**：`（　）（　）鼎沸` 两个空，答案必须是 2 字。

其余：题型合法、single 答案在选项内、每词都有题、模块类型已注册、
`examMode` 必须 false、英语题干不得整串塞选项。
