## F1 · 错题 AI 启发式讲评（P0）

**范围**：`src/core/ai/prompt.ts`、`src/core/ai/aiClient.ts`、`src/views/Mistakes.vue`、`src/views/Settings.vue`、`tests/settings-keys.test.ts`（登记键）。

**要求**
1. `prompt.ts` 是**纯函数**：输入（题干 / 正确答案 / 错因 `mistakeCause` 四值 / 孩子答的答案）→
   System + User Prompt。必须：限字数、**注入防御**（题目是外部内容，清除"忽略以上指令"类模式）、
   屏蔽敏感词。**导向必须是启发思路，不直接给答案**（主程会逐字看你定稿的 Prompt）。
2. `aiClient.ts`：`deepseekClient`（原生 fetch + SSE 流式 + `AbortController`）、
   `ollamaClient`（探测 `http://localhost:11434` + 调用）、`router`（DeepSeek 优先，
   超时/失败 → Ollama → 再降级静态解析，每级都要有可断言的失败原因）。
3. `Mistakes.vue`：错题卡「💡 启发一下」→ 抽屉 + 打字机流式；期间按钮 loading + 可中断；
   三级降级要在 UI 上给不同的人话提示（别都是"出错了"）。
4. `Settings.vue`「🤖 AI 助手设置」AppCard：API Key + 模型名（如 `deepseek-chat`）。
   **Key 存储策略（方案 0-①，别自作主张改）**：默认**会话内有效、不落盘**；
   可选「记住我的 Key」= WebCrypto AES-GCM + PBKDF2(家长口令)，只落密文 + salt + iv。
   **Tauri Keychain 不在本任务内**（需 Rust 插件，已单开）。
5. 新 settings 键按**设备级**登记（不按 profileId 分片），过 `check:settings-keys`。

**验收**：单测覆盖 超时降级 / SSE 流式解析 / 注入防御 / AbortController 中断；
e2e 用 `page.route` mock 断言打字机渲染与降级提示。
**反向验证**：把 router 超时设为 0 → 测试必须红；还原后绿。**贴红绿原文。**

## F2-core · 同步通道与合并复用（P0，不碰 UI）

**范围**：`src/core/sync/webdavClient.ts`、`src/core/sync/syncManager.ts`、单测。
**禁止**：不碰任何 `.vue`；不碰 `tests/settings-keys.test.ts`；**不许重写合并逻辑**。

**要求**
1. `webdavClient.ts`：原生 `fetch` 实现 PUT / GET / PROPFIND；URL 拼接抽成纯函数；
   失败要分类（网络不可达 / 401 / 404 / **CORS**）并给可断言的错误类型。
2. `syncManager.ts`：打包复用 **`buildBackupV2()`**（别自己组装 JSON）→ 上传
   `fls-backup-<profileId>.json` → 下载 → **复用 `planMerge` + `applyMergePlan`** → 落库。
   **合并前置校验：防跨档案串数据**（档案 id 不匹配直接拒绝，不进合并）。
   **并发冲突**：以 `lastStudiedAt` 为基准，产出"本机新 / 远端新 / 冲突"三态供 UI 决策
   （UI 是 F2-UI 的事，你只产出可断言的三态结果）。
3. 环境分支用 `@core/pwa/isTauri`；**CORS 受限要在错误里如实说明**（方案 0-①），
   并提示可回退到既有的「导出文件 / 导入文件」通道。

**验收**：单测（URL 拼接 / 前置校验 / mock fetch 的成功与四类失败分支 / 三态判定）。
**反向验证**：把合并临时改成"覆盖式"（丢弃本地更晚的行）→ 测试必须红；还原后绿。
