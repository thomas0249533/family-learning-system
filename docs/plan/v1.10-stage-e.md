## E1 · FSRS 时间口径本土化（P0 数据债）

**问题**：`fsrs.ts` 的 `due` / `last_review` 走 UTC（`toISOString()`），而
`reviewScheduler.ts` 全链路是本地口径（`getFullYear/getMonth/getDate`，禁
`toISOString` 做日期比较）。东八区晚 20:00 后的学习记录，持久层存的是 UTC 的
"昨天" → 同一操作在不同时段算出的下次复习间隔可能差 1 天。

**动笔前先审计三类点**：
1. 写入口：FSRS 调度结果落库前的所有序列化点；
2. 读入口：所有按字符串前缀/切片比日期的地方（时区偏差的直接受害者）；
3. 消费方：`reviewScheduler`、`applyDecay` 的 7 天降级规则、打卡连续性、
   周报的"本周"边界（E3 依赖它）。

**修法**（用户指示）：统一 `localDayKey`（`YYYY-MM-DD` 本地）或带时区 ISO
（`YYYY-MM-DDTHH:mm:ss.SSS+08:00`）。建议「日」粒度字段用前者、「时刻」粒度字段用
后者，并在 db 类型上写清口径注释。

**数据迁移是本体，不是附加题**：已有行的 `due`/`last_review` 是 UTC 串，换口径后
旧行日期部分可能整体差一天。**先写迁移测试再动写入口**：造 UTC 旧行 → 走迁移 →
断言本地口径正确、无重复无遗漏、复习队列不多不少一条。没有迁移测试不许改写入口。

**验收**：单测覆盖 20:00 / 23:59 / 00:01 三个时区边界；e2e 覆盖「晚上做题 →
次日复习列表正确」；反向验证：把写入口改回 UTC → 迁移测试必须红。

## E2 · 智能错题重组（进阶错题本）

**现状**：错题三级 `none/partial/mastered`，连续答对 2 次升级；只是"打标 + 复习"。

**目标**：按错因（`careless` / `knowledge`）+ FSRS 遗忘曲线，把长期没搞懂的错题
重新打包成一个临时 `special` 包，让孩子集中攻克。

**必须遵守的既有铁律**（缺一不可）：
1. 临时包 manifest 必须同时写 `examMode: true` 与 `sourceUnitIds`
   —— 否则无题目导航 / "基于 0 个单元"；
2. `manifest.dependencies` 必须为空 —— 非空会被当聚合包；
3. **进度归属**：临时包的进度行 `packageId` 由归属解析决定（V1.3 口径）。
   错题重组的练习进度必须回流到**原 KP 所属包**，否则原包掌握度不更新、
   家长端数字与孩子实际水平脱节。**这是本项最大的坑：先写归属测试，再写 UI。**

**设计要点**：
- 临时包 id 稳定（如 `special-weakpoints-auto`），每次生成**覆盖**旧包，不累积；
  包是设备级资产、不进备份（裁决 1），重建策略 = 按需重新生成；
- 选题规则：错因 `knowledge` 或连续失败 ≥2 次优先；`careless` 少量混入
  （全混 `careless` 会让孩子练"粗心"而不是练不会的）；
- UI 入口：错题本页「一键生成练习卷」+ 家长端确认（生成即覆盖，要有明示）。

## E3 · 家长周报/月报卡片

**现状**：`Parent.vue` 已有趋势数据；`html2canvas` 与 `jspdf` **已是项目依赖**
（`reportGenerator` 在用）—— 本项不引入任何新依赖。

**目标**：生成本地周报卡片（PNG / PDF），家长可保存可转发。

**口径铁律**：
- 周报所有掌握率数字必须走 `computeMasterySummary` + `masteryBySubject`
  （Stage C 立过的规矩，禁止就地写公式）；
- 日期一律本地口径（E1 落地后复核一遍周报的周期边界）。

**隐私**：纯本地生成、不上传；卡片含儿童学习数据，分享动作由家长显式触发，不自动外发。
