# V2.0 任务清单与提交纪律

> 方案见 `docs/plan/v2.0-offline-ai-resume.md`（含 §0 五处侦察修正，施工前必读）

## 通用纪律（所有代理）

1. **提交只准 path-whitelist**：`git add` 只加自己文件集内的路径，`git commit -- <显式文件列表>`。**PNG 一律显式文件名，绝不 `git add docs/screenshots/`**（Stage F 出过"互卷"事故）。
2. **绝不准 `--no-verify`**（pre-commit 会跑 `tokens:check` + `typecheck:test`）。
3. **零重型前端依赖**；唯一例外是 A3 的 `@tauri-apps/api@2`（见方案修正二），且只准在 `src/core/ai/candle/ipc.ts` 里 import。
4. **样式只走语义 token**（`--{tone}-text` 用于 `color:`，`--{tone}-color` 用于图形色）；`check:hex` / `check:text-color` / `lint:styles` 不许红。
5. 新增带冒号的字符串字面量前先 `npm run check:settings-keys` 自查。
6. `npm run verify` / `cargo build` / e2e 需要 `dangerouslyDisableSandbox: true`；e2e 用 `CODEBUDDY_SAFE_DELETE_ENABLED=0 PW_TRACE=off npx playwright test <spec>`。
7. 完成后向 `docs/memory/2026-10-23-v2.0.md` 用 `cat >>` **追加**一节（不要整文件重写，可能有并发），并纳入最后一笔提交。

## A1a · Candle 编译可行性冒烟（go / no-go 闸门 · 批一）

**只做三件事，不要多写一行业务代码**：
1. `src-tauri/Cargo.toml` 加 `candle-core`、`candle-transformers`（**先查清解析到哪个版本**，再确认该版本里 `models::quantized_qwen2` / `quantized_llama` 是否存在——用源码或 `cargo doc` 证实，**不准假设**）。
2. 写一个最小 `src-tauri/src/ai/mod.rs`：`pub fn backend_probe() -> &'static str` 之类不依赖模型的函数 + `#[tauri::command] fn ai_backend_info()` 返回 `{available: bool, reason: Option<String>}`（此刻 available=false 也可，只要能编译）。
3. `cargo build --release` **或** `cargo check --release`（先 check 省时间），**记录耗时**。

**报回主程**：解析到的 candle 版本、`quantized_*` 模块是否存在、check/build 是否绿、耗时、是否触发 OOM/磁盘告警。
**若红**：立刻停手，报告完整错误（`error[E...]` 前 20 行）+ 你判断的根因，**不要自己绕**（绕法由主程裁决：可能改为 feature gate）。

## A1b · 推理 command + 流式（批二，A1a 绿后）

- `#[tauri::command] async fn ai_chat_stream(window, id: String, prompt: String)`：后台 task 逐 token `emit("ai-stream-chunk", {id, delta})`，结尾 `ai-stream-done{id}` / `ai-stream-error{id, code}`。
- 错误码：`no-model` / `model-corrupt` / `oom` / `decode-failed`。
- 模型路径：`app_data_dir()/models/*.gguf`；加载失败不得 panic。
- 首字必须流式（**不准等全部生成完再返回**）。

## A2 · 模型管理（批二）

- Rust：`ai_model_status` / `ai_model_download(url, expectedSha256)`（reqwest 流式 + `emit("ai-model-progress", {received,total})`）/ `ai_model_pick()`（`tauri-plugin-dialog` 拿路径，读取校验仍在 Rust）/ `ai_model_remove()`。
- SHA-256 校验用 `sha2`；不匹配删文件并返回 `model-corrupt`。
- 前端：`src/views/settings/LocalAiCard.vue`（自包含），`Settings.vue` 只加 import + 一个 `<LocalAiCard/>`。
- capability：只加 `dialog:allow-open`（**不给 fs 权限**）。

## A3 · 前端路由（批二）

- `src/core/ai/candle/ipc.ts`：唯一 `@tauri-apps/api` 引用点；非 Tauri / 无模型 → 直接返回 `null`（不抛）。
- `src/core/ai/candle/candleClient.ts`：`streamCandle({system,user,onDelta,signal})` → 复用 `aiClient` 的 `AiReader` 风格，便于 Mock。
- `aiClient.ts`：新增 `requestAiHint` 之外的**新顺序**常量/函数，**不要改既有 `requestAiHint` 的 ollama→deepseek 语义**（已有多条测试钉住）。
- `aiMessages.ts`：`AiEngine` 加 `'candle'`，补 `AiFailReason` 的 `unavailable`/`no-model`/`oom` 人话文案。
- 单测：降级顺序（candle 不可用 → ollama → deepseek → 规则）、chunk 拼接、aborted 不降级。

1. **db v5**：`topicSessions: '++id, [profileId+topicId], profileId, packageId, updatedAt'`，类型 `TopicSessionRecord`（字段见方案）。**每行必须带非空 `profileId`**。

7. **单测 + e2e**：单测覆盖快照/恢复/腐坏/答题卡网格；e2e：答 10 题 → reload → 出现"继续" → 点击后停在第 11 题。
