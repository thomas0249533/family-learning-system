# 学习包错误码字典

## 错误码 (E)

| Code | 含义 | 修复方向 |
|---|---|---|
| E001 | 学习包不是有效 JSON 对象 | 确认顶层是 `{}` |
| E002 | 缺少 manifest | 补 manifest 元数据 |
| E003 | 缺少 manifest.packageId | 补 packageId，如 `math-4-up-rjb` |
| E004 | 知识点 id 重复 | 保证每个知识点 id 唯一 |
| E005 | 题目缺少 id | 每道题加唯一 id |
| E006 | 题目缺少 type | type 应为 single/blank/multiple/... |
| E007 | 题目缺少 answer | 补标准答案 |
| E008 | 题目无知识点关联 | 在题目或 topic 提供 knowledgePointIds |
| E009 | 题目引用了不存在的知识点 | 检查 knowledgePoints 是否包含该 id |
| E010 | JSON 语法错误 | VSCode 打开，修复红色波浪线 |

## 警告码 (W)

| Code | 含义 | 建议 |
|---|---|---|
| W001 | 知识点缺少 id | 建议语义化命名，如 `math-formula-001` |
| W002 | 题目 id 重复 | 保证唯一，否则错题本混乱 |

## 运行时错误码（出现在家长面前的）

上面 E/W 是**内容作者**看的校验码（`npm run validate` 的输出），家长不会见到。
下面这一组是**运行期**抛给界面的，必须翻译成人话才能显示 ——
映射表在 **`src/core/errors/messages.ts`**（唯一来源，UI 只做选择、不做翻译）。

| Code（`Error.code` / `Error.name`） | 何时出现 | 界面怎么说 | 有按钮吗 |
|---|---|---|---|
| `stale-local-data` | 备份预览之后本机又产生了新的学习记录（A6 · L2 陈旧快照守卫） | 「检测到新的学习记录」+「为了数据安全，这次没有写入任何一行。请返回首页同步一下，再重新预览一次并导入。」 | 「重新选择文件」 |
| `profile-limit` | 导入后档案数会超过 4（AC-P2-14，整笔拒绝） | 「导入后会超过 4 个档案」+「先导出一份备份，再删掉一个不用的档案」 | 「导出并删除旧档案」（跳设置页 `#family-backup`） |
| `DataCloneError` | Dexie 拒绝写入（待写对象里有不能被结构化克隆的东西，典型是 Vue 深层 reactive 代理） | 「这次导入没有写入任何数据」+「刷新页面后重新导入；反复出现请把技术细节反馈给我们」 | 无（家长能做的只有重试） |
| 其它 / 未知 | — | 兜底文案：「这次导入没有写入任何数据，本机数据保持原样」 | 无 |

### 三条硬约束

1. **界面上不出现 Code 本身**。码只允许出现在折叠的「技术细节」里（供排障复制）。
   自查：`npx vitest run tests/error-messages.test.ts` 断言了每个已知码的标题/提示
   都不含该码，且都是中文。
2. **每条文案都要回答"现在怎么办"**。只写"导入失败"等于没说 —— 家长不知道该重试
   还是该换文件（AC-P2-15 的教训）。
3. **`profile-limit` 的标题必须保留「超过 4 个档案」**：`tests/e2e/backup-roundtrip.spec.ts`
   断言的就是这几个字。改文案时同步改断言，别只改一边。
