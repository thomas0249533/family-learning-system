# 视觉回归清单（B7 · 人工基线）

> 目的：在无法自动截图（Playwright 内核不可用）时，提供**可复现、可执行**的人工核对基线。
> 用法：启动 `npm run dev` → 逐页在「浅色 / 深色」两态下核对下表每一项 → 截图存入
> `docs/screenshots/`（命名 `{页面}-{light|dark}.png`）作为留档基线。
> 主题切换路径：设置页「外观设置」→ 主题模式（浅色/深色）；学段预设（小学/初中/高中）。
> 建议同时核对 **3 学段 × 浅/深 = 6 组** 的关键页（至少首页），确认无「深色串成学段浅色」。

## 命名规范

`docs/screenshots/{页面键}-{light|dark}.png`，例：`home-light.png` / `report-dark.png`。
若需覆盖学段，可加后缀：`home-primary-dark.png`、`home-senior-light.png`。

## 全局复核项（每态都过一遍）

- ☐ **首屏无 FOUC**：刷新后首帧即目标主题（无「先白后深 / 先初中后小学」闪色）。
- ☐ **持久化**：切换主题/学段/字号后刷新，三项设置 100% 保持。
- ☐ **字号单次缩放**（B1）：small/medium/large 逐档切换，naive-ui 组件文本随档变化，且无非预期「双重放大」。
- ☐ **深色图表可读**（B3）：首页环形图文字、tooltip、色块在深色下清晰。
- ☐ **打印固定浅色**（B3）：`Ctrl+P` 预览为浅色。
- ☐ **Tauri 分端**（B4）：Web 端 SW 更新条正常；桌面端不出现该条（需在 Tauri 构建下验证）。
- ☐ **6 组主题**：小学/初中/高中 × 浅/深，首页配色与学段个性一致；「深色 + 非默认学段」为对应学段深色（非学段浅色）。

## 已自动化的部分（替代项）

- 组件层**硬编码颜色**门禁：`npm run lint:styles`（stylelint `color-no-hex`）+ `npm run check:hex`（零依赖）。
- 双源配色防漂移：`npx vitest run tests/palette-consistency.test.ts`（6 组 200+ 断言）。
- 成就判定：`npx vitest run tests/achievements.test.ts`（28 枚逐项）。
