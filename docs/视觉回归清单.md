# 视觉回归清单（V2 · 人工基线）

> **V2 变更（V1.6 · Stage B · B5）**
> 1. 前提变了：V1 写"无法自动截图（Playwright 内核不可用）"，那条早已不成立 ——
>    `tests/e2e/` 现在有 3 份截图/像素矩阵（见文末「已自动化」）。**本清单因此收窄**，
>    只留"截图看不出来、必须人判断"的部分，不再重复自动化已经能挡的东西。
> 2. 新增 4 个专项：**多档案（家庭墙）**、**打印与分页**、**自定义包管理**、**导入向导**。
>    这四块是 V1.4–V1.6 长出来的，V1 清单里一条都没有 —— 等于从未被人眼验过。
> 3. 全局项补了「焦点环在两态下可见」与「弹窗层级」。
>
> 用法：`npm run dev` → 逐页在「浅色 / 深色」两态下核对 → 截图存 `docs/screenshots/` 留档。
> 主题切换：设置页「外观设置」；学段预设（小学 / 初中 / 高中）。
> 纪律：**每态都要过一遍全局项**，别只盯自己改的那一页。

## 命名规范

`docs/screenshots/{页面键}-{light|dark}.png`，例：`home-light.png` / `family-wall-dark.png`。
带学段时加中缀：`home-primary-dark.png` / `home-senior-light.png`（与 `theme-presets.spec.ts`
的输出目录 `docs/screenshots/{preset}/` 保持一致，别造第二种命名法）。

## 专项 1 · 多档案（4 档案上限）

| # | 场景 | 核对项 |
|---|---|---|
| 1.1 | 建满 4 个档案后点「新建档案」 | 弹**弹窗**（不是飘字）：标题含「最多 4 个档案」，正文说明"先导出再删"，主按钮「导出并删除旧档案」；Esc / 「知道了」能关 |
| 1.2 | 点该按钮 | 跳到设置页并**滚到「📤 导出」卡片**（`#family-backup`），而不是停在页面顶部 |
| 1.3 | `/family-wall` 并排 | 4 个孩子各自一列/一屏；**名字与字首不串**；进度条颜色沿用各自学段预设；深色下卡片边界仍可分辨 |
| 1.4 | `/family-wall` 只有 1 个档案 | 不出现"单列挤在左边"的怪样子；有空态或明确提示，而不是一片空白 |
| 1.5 | 切换档案（AppShell 切换器） | 切换后首页/复习/错题的数字**全部换成该档案**；不残留上一个档案的成就或错题（这是"串档案"的典型症状） |
| 1.6 | 档案名超长（15 字以上） | 切换器与家庭墙都不撑破布局；截断处有省略号而不是硬切 |

## 专项 2 · 打印与分页

| # | 场景 | 核对项 |
|---|---|---|
| 2.1 | `/achievements/print` 直接打开 | 恒浅色（不跟随深色主题）；页眉有导出日期；无导航/按钮等交互控件 |
| 2.2 | `Ctrl+P` 预览 | 分页处**卡片不被拦腰切断**；每页有标题上下文；页脚页码正确 |
| 2.3 | 打印 28 枚成就 | 页数符合预期（无"最后一页只剩一枚"这类孤行）；剪影占位不印出真实信息 |
| 2.4 | 报告页 `Ctrl+P` | 图表与表格不被切段；导出的 PDF 为浅色 |
| 2.5 | 学习页 `Ctrl+P` | 题目/选项在纸上可读；答案区不被误印（若设计上不印） |

## 专项 3 · 自定义包管理（`/parent` → 🧩 自定义成就包）

| # | 场景 | 核对项 |
|---|---|---|
| 3.1 | 空态 | 有明确"还没有自定义包"的说明 + 导入入口，不是空白面板 |
| 3.2 | 导入一个包 | 卡片显示包名/卡数/启用状态；**导入完即启用**（不会导了却看不到） |
| 3.3 | 停用 / 回滚 | 停用后图鉴里该卡消失，但**证据（解锁记录）不被销毁**；回滚按钮可用 |
| 3.4 | 校验失败 | 错误提示指到具体哪一条成就/哪个字段，不是一句"格式不对" |
| 3.5 | 深色下 | 卡片边框/状态徽章可读；停用态与启用态有**非颜色**的差异（只差一点深浅等于没差） |

## 专项 4 · 导入向导（`/settings` → 📥 从备份导入）

| # | 场景 | 核对项 |
|---|---|---|
| 4.1 | 第 1 步 | 「怎么把备份文件弄到这台设备上？」折叠面板**默认收起**、可点开、可键盘聚焦（Tab 到它有焦点环）；展开后微信/U 盘两套步骤排版不错乱 |
| 4.2 | 预览态 | ⚠️ 导入期提示条（`--warning-soft` 底 + 左侧色条）在浅/深两态都清晰，**不与错误红混淆** |
| 4.3 | 拒绝态 · 档案超限 | 出现「导出并删除旧档案」按钮；点它跳到设置页并滚到导出卡片 |
| 4.4 | 拒绝态 · 版本太新 / 文件损坏 | **不出现**任何按钮（这两类没有确定动作，给了就是假动作）；技术细节折叠在 `<details>` 里 |
| 4.5 | 执行失败 | 标题是中文人话（如"检测到新的学习记录"），**界面上不出现 `stale-local-data` 这类码**；码只出现在折叠的技术细节里 |
| 4.6 | 连点确认 | 2 秒内狂点只产生一条结果提示；按钮不闪成假 loading |

## 全局复核项（每态都过一遍）

- ☐ **首屏无 FOUC**：刷新后首帧即目标主题（无「先白后深 / 先初中后小学」闪色）。
- ☐ **持久化**：切换主题/学段/字号后刷新，三项设置 100% 保持。
- ☐ **字号单次缩放**：small/medium/large 逐档切换，naive-ui 组件文本随档变化，无非预期「双重放大」。
- ☐ **深色图表可读**：首页环形图文字、tooltip、色块在深色下清晰。
- ☐ **打印固定浅色**：`Ctrl+P` 预览为浅色。
- ☐ **Tauri 分端**：Web 端 SW 更新条正常；桌面端不出现该条（需在 Tauri 构建下验证）。
- ☐ **6 组主题**：小学/初中/高中 × 浅/深，首页配色与学段个性一致；「深色 + 非默认学段」为对应学段深色。
- ☐ **焦点环可见**：键盘 Tab 走过首页 → 任一按钮/链接/基元，焦点环在**两种底色上**都看得见（深色下最容易丢）。
- ☐ **弹层层级**：档案上限弹窗、删除确认、成就详情弹层，在深色下遮罩与卡片底色不糊成一片。
